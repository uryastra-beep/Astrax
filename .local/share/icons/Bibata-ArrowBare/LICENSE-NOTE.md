# Bibata-ArrowBare

An arrow-only cursor theme for Astrax's reactive cursor: the dynamic-cursors plugin draws the colored
glow around it, so the theme itself is just the plain arrow.

It is derived from [Bibata Cursor](https://github.com/ful1e5/Bibata_Cursor) by Abdulkaiz Khatri
(`Bibata-Modern-Ice`, v2.0.6), which is licensed under the **GNU General Public License v3.0**.
